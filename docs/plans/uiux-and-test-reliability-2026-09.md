| Certification can serve the wrong backend or old source | Record source/environment digests at build, verify disk receipt and served opaque build ID before world creation | Tier 2 |

| A second run or cleanup can destroy an active world | Hold one workspace lock throughout preflight, setup, browser execution, archive, and teardown; cooperating build/env/SQL commands use the same lock | Tier 2 |

| Retained diagnostics lose module-local identities and repeat partial writes | Persist typed stage checkpoints with world/group ownership; split preparation from submission and forbid blind submit retries | Tier 1/2 |
| Live latency timing begins after the producer finishes | Measure from the explicit mutation callback and archive failure samples as well as passes | Tier 2 |
