## Why this step exists

Step 3 removed 41 uncalled Server Actions, seven dead component files, about 140 unreferenced exports, twelve unused dependencies and several duplicated helpers, and added four Tier 2 checks. The owner does not want to run such a sweep again. The gap: no gate catches unused files and exports, lint suppressions need no reason, CodeRabbit cannot review the whole tree (150-file limit on the current tier) and is not part of the routine, and "minimal code" has no mechanical check.

## Candidates to evaluate, with the evidence behind each

1. **Unused exports and files as a gate.** The one-off knip run plus `git grep` found the dead code in Step 3; the security-relevant subclass (exported Server Actions without a product importer) is already a Tier 2 test in `lib/security/server-action-authorization.test.ts`. Make the general class a gate.
2. **Compiler flags.** Check `noUnusedLocals`, `noUnusedParameters`, `exactOptionalPropertyTypes` and `noUncheckedIndexedAccess` against the current tree; enable what the tree already satisfies, plan the rest.
3. **A deletion pass per slice.** The slice protocol should require, before acceptance, a pass that asks for every added file and function whether the outcome survives without it, with the count of lines added and removed recorded in the slice record. Decide whether the `/simplify` skill or a review checklist is the mechanism, and whether the reviewer must be a different session than the implementer.
4. **CodeRabbit per commit-sized diff.** `bun run review` is the only sanctioned entry point and refuses more than 150 files. Make a per-slice review on the slice's diff part of the protocol, and record how the six findings of Step 3's directory-scoped reviews were dispositioned as the model for future ones.
5. **Duplicated helper detection.** Step 3 consolidated seven copies of `formatFileSize`, three date formatters, four duration formatters and six search normalizers. Evaluate a convention test that flags identically named exported functions across `lib/` and `components/`, or a jscpd-style duplication gate with a threshold.
6. **Conventions that exist only as prose.** Go through AGENTS.md "Language And Coding Standards" and the `werkflow-design` skill and list every rule that a lint rule, a convention test or a type could enforce. Examples already known: hex literals in JSX (done), raw `bg-green-*` status colors (backlog), `strokeWidth` props on icons, `rounded-2xl` and larger radii, hardcoded German strings deep in logic.
7. **Fourteen local date formatters** remain by design (CL-D2); decide whether a shared formatter with explicit variants is the minimal solution now that the campaign is over.
8. **The two very large action modules** (`lib/time-tracking/actions.ts` about 3,900 lines, `lib/documents/actions.ts` about 4,200 lines, CL-D7) are a maintainability risk; splitting is a rewrite. Propose the seam, do not split in this step unless the owner asks.
