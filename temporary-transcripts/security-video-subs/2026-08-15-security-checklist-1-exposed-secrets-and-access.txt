Exposed database credentials, public.env files,
hard coded API keys or secrets,
weak or missing authentication,
missing server side auth checks,
users able to access other users' data,
open or overly permissive database read and write permissions,
misconfigured Firebase, Superbase, S3 or storage buckets,
admin routes left unprotected,
debug pages or developer tools exposed in prod,
build logs leaking secrets,
for both error messages,
leaking stack traces or internal details,
secrets or sensitive data committed to Git or Git history,
secrets involved in front-end JavaScript,
client-side only security checks,
