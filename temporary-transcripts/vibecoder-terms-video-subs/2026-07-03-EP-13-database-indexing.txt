Today's term, Database Indexing.
An index is a pre-sorted shortcut that your database builds for one specific column.
And this shortcut allows the database to get data back to you quicker.
Instead of reading through every row in the table, it only has to read through some.
You can also think of a database index like the index of a book.
Without the index, if you wanted to find every occurrence of mitochondria, for example, you'd
have to read through all 900 pages to be sure that you found every one.
If you have an index, though, you can search the index for the specific term you're looking
for and that entry will just show you all of the occurrences.
So if you're Vibecoding, make sure to instruct ClodCode or Codex to set up proper database
indexes where applicable.
